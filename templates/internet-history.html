History of the Internet: Networks, Protocols & Infrastructure

The Internet is the global system of interconnected computer networks that communicate using the Internet Protocol Suite (TCP/IP). Engineered from foundational research sponsored by the U.S. Department of Defense's Advanced Research Projects Agency (DARPA) in the late 1960s, the Internet emerged to solve the challenge of robust, survivable, and decentralized packet-switched communication across heterogeneous hardware platforms.

Unlike the World Wide Web—which is an application-layer service composed of interlinked hypertext documents and media—the Internet forms the underlying telecommunications infrastructure, routing protocols, physical backbones, and transport architectures that transmit raw data packets globally. From initial 50 kbps ARPANET Interface Message Processors (IMPs) to the formalization of TCP/IP, hierarchical DNS, high-speed fiber backbones, BGP routing, and IPv6 address deployment, this timeline explores the engineering milestones that built modern global internetworking.

Detailed Milestones

1. 1969: ARPANET Established (First Packet-Switching Transmission)

Event: The Advanced Research Projects Agency (ARPA) deployed Interface Message Processors (IMPs) connecting university computers across UCLA, Stanford Research Institute, UC Santa Barbara, and the University of Utah. The first packet-switched message ("LO") was transmitted between UCLA and Stanford on October 29, 1969.

Proved the viability of packet switching over traditional circuit-switched telephone lines, establishing dynamic routing and decentralized survivability as core principles of computer networking.

Sources:

  • DARPA Innovation Timeline: ARPANET
  • Computer History Museum: 1969 ARPANET
  • Internet Hall of Fame: Leonard Kleinrock

2. 1971: The First Network Email & Header Routing Standards

Event: Computer engineer Ray Tomlinson at Bolt, Beranek and Newman (BBN) developed the SNDMSG and CPYNET programs, creating network email and selecting the '@' symbol to separate local user accounts from remote host names.

Shifted network utility from purely synchronous remote computation and file transfers to asynchronous person-to-person messaging, creating the earliest standard for network addressing.

Sources:

  • Internet Hall of Fame: Raymond Tomlinson
  • Internet Society: A Brief History of the Internet
  • IETF RFC 561: Standardizing Network Mail Headers

3. 1972: Telnet Protocol Specification & RFC Standardization

Event: The network working group published RFC 318 specifying the Telnet protocol for remote terminal connections. Jon Postel organized Request for Comments (RFC) management, and ARPANET was publicly demonstrated to international researchers at the ICCC in Washington, D.C.

Established standardized virtual terminal communication across heterogeneous computer architectures and formalized the RFC mechanism as the foundational open-documentation model for network protocols.

Sources:

  • IETF RFC 318: Telnet Protocol Specification
  • Internet Hall of Fame: Jon Postel

Back to Summary Table

4. 1973: Invention of Ethernet Local Area Networking (LAN)

Event: Robert Metcalfe and David Boggs at Xerox PARC invented Ethernet, utilizing Carrier Sense Multiple Access with Collision Detection (CSMA/CD) to link computers over coaxial cable.

Created the universal physical and data-link layer standard (IEEE 802.3) for high-speed local packet broadcast, bridging personal workstations directly into wide-area network gateways.

Sources:

  • IEEE Honors: Robert Metcalfe Biography
  • Computer History Museum: Ethernet Invention

Back to Summary Table

5. 1974: Transmission Control Protocol (TCP) Design

Event: Vinton Cerf and Robert Kahn published "A Protocol for Packet Network Intercommunication" in IEEE Transactions on Communications, formally specifying TCP (RFC 675).

Engineered the foundational architecture for internetworking, allowing disparate packet networks (satellite, radio, landline) to seamlessly exchange packets using end-to-end reliability and gateways.

Sources:

  • IEEE Transactions: Cerf & Kahn Protocol Paper
  • ACM A.M. Turing Award Citation
  • IETF RFC 675: Specification of Internet Transmission Control Program

Back to Summary Table

6. 1978: Separation of TCP and IP & Creation of IPv4

Event: Vint Cerf, Jon Postel, and Danny Cohen split the original monolithic TCP program into two distinct layers: TCP for reliable connection-oriented transport, and IP for stateless packet addressing and routing, defining IPv4.

Established the modular layered architecture of the modern Internet protocol stack and defined the 32-bit dotted-decimal IP address space (providing ~4.3 billion addresses).

Sources:

  • IETF RFC 791: Internet Protocol (IPv4) Specification
  • Internet Society: Protocol Layering History

Back to Summary Table

7. 1981: Usenet & UUCP Decentralized Dial-Up Networking

Event: Duke University graduate students Jim Ellis and Tom Truscott deployed Usenet using the Unix-to-Unix Copy Protocol (UUCP) over dial-up telephone modems.

Demonstrated decentralized, peer-to-peer store-and-forward message routing across wide geographic areas, proving that digital networks could operate without military or government funding.

Sources:

  • USENIX: The History of Unix Networks and Usenet
  • Computer History Museum: 1981 Timeline

Back to Summary Table

8. 1983: ARPANET Flag Day (Official Birth of the Internet)

Event: On January 1, 1983 ("Flag Day"), ARPANET permanently deactivated the legacy Network Control Program (NCP) and mandated that all connected host computers communicate exclusively via TCP/IP (RFC 801).

Marked the formal operational birth of the Internet by unifying military, university, and international networks into a single, cohesive, globally routable internetwork.

Sources:

  • IETF RFC 801: NCP/TCP Transition Plan
  • Computer History Museum: TCP/IP Becomes Official

Back to Summary Table

9. 1983: The Domain Name System (DNS) Invented

Event: Paul Mockapetris at USC Information Sciences Institute designed the Domain Name System (RFC 882 and RFC 883), establishing hierarchical name resolution with top-level domains (.com, .edu, .gov, .org, .net).

Eliminated the fragile central distribution of the static HOSTS.TXT master file, replacing it with a distributed, delegable, and cacheable database capable of scaling to hundreds of millions of nodes.

Sources:

  • IETF RFC 882: Domain Names - Concepts and Facilities
  • Internet Hall of Fame: Paul Mockapetris

Back to Summary Table

10. 1986: NSFNET National Backbone Launched

Event: The U.S. National Science Foundation established NSFNET, deploying a 56 kbps backbone linking supercomputer centers at Princeton, Cornell, UCSD, UIUC, and NCAR, later upgraded to T1 (1.5 Mbps) and T3 (45 Mbps).

Expanded Internet access beyond defense contractors into the national academic community, providing the core long-distance fiber transmission infrastructure that carried academic and scientific network traffic.

Sources:

  • National Science Foundation: NSFNET History
  • Merit Network Heritage: Managing NSFNET

Back to Summary Table

11. 1988: Border Gateway Protocol (BGP) & The Morris Worm

Event: Kirk Lougheed and Yakov Rekhter drafted Border Gateway Protocol (RFC 1105) to route traffic between autonomous systems. Concurrently, the Morris Worm infected 10% of internet-connected hosts, leading to the formation of the CERT Coordination Center.

Supplied the scalable path-vector inter-domain routing protocol that binds modern global telecommunication carriers together, and established cybersecurity incident response as an institutional necessity.

Sources:

  • IETF RFC 1105: Border Gateway Protocol (BGP)
  • Carnegie Mellon University: CERT Coordination Center History

Back to Summary Table

12. 1992: Internet Society (ISOC) Founded & IETF Formalization

Event: Vint Cerf, Bob Kahn, and Lyman Chapin established the Internet Society (ISOC) to incorporate institutional governance, administrative support, and financial backing for the Internet Engineering Task Force (IETF).

Safeguarded the open, voluntary, consensus-driven standards process ("rough consensus and running code"), ensuring that core Internet protocols remained unencumbered by proprietary corporate patents.

Sources:

  • Internet Society: Institutional Mission & History
  • IETF: History and Operating Philosophy

Back to Summary Table

13. 1995: NSFNET Decommissioned & Commercial ISP Backbone Transition

Event: On April 30, 1995, the National Science Foundation decommissioned the NSFNET backbone, transferring national Internet traffic to private commercial Internet Service Providers (ISPs) interconnected through Network Access Points (NAPs) and Internet Exchange Points (IXPs).

Finalized the transformation of the Internet from a federally subsidized research network into a privatized, competitive, commercial telecommunications infrastructure capable of global market scaling.

Sources:

  • National Science Foundation: Transition to Commercial Internet
  • Computer History Museum: 1995 Infrastructure Transition

Back to Summary Table

14. 1998: ICANN Established & IPv6 Specification (RFC 2460)

Event: The Internet Corporation for Assigned Names and Numbers (ICANN) was created under a U.S. Department of Commerce mandate to coordinate global IP address allocations and DNS root zones. Concurrently, the IETF published RFC 2460 formalizing IPv6.

Established multi-stakeholder governance over global critical Internet identifiers and engineered the 128-bit address space, permanently averting IPv4 address space exhaustion.

Sources:

  • ICANN: History and Multi-Stakeholder Model
  • IETF RFC 2460: Internet Protocol, Version 6 (IPv6) Specification

Back to Summary Table

15. 2003: IEEE 802.11g Wi-Fi & Residential Broadband Expansion

Event: The IEEE ratified the 802.11g wireless networking standard (providing 54 Mbps throughput in the 2.4 GHz band), while DSL, cable modems, and fiber-to-the-home infrastructures eclipsed analog dial-up modems.

Untethered consumer and corporate devices from physical ethernet cables, democratizing high-speed wireless packet routing and laying the infrastructure for always-connected computing.

Sources:

  • IEEE Standards Association: 802.11g Standard
  • Internet Society: Global Infrastructure Report

Back to Summary Table

16. 2012: World IPv6 Launch & Global DNSSEC Cryptographic Deployment

Event: On June 6, 2012, major international network operators, content delivery networks (CDNs), and hardware vendors permanently enabled IPv6. Simultaneously, DNS Security Extensions (DNSSEC) completed full cryptographic signing across all 13 root DNS name servers.

Marked the permanent operational production deployment of next-generation internetworking and established cryptographic origin authentication for domain lookup, protecting global routing against packet poisoning and MITM attacks.

Sources:

  • Internet Society: World IPv6 Launch Archive
  • ICANN: DNSSEC Root Zone Security Deployment
