Key Milestones of the Web

Quick Summary

Year Milestone Event Impact
1989 Proposal for the Web Conceived global hypertext linking system
1990 First Server & Browser Built working HTTP, HTML, and URL prototypes
1991 Web Goes Public Announced software outside CERN community
1993 Public Domain & Mosaic Royalty-free code and graphical browser launch
1994 W3C Founded Established open web standards body
1995 JavaScript & E-Commerce Added client-side scripting and online shopping

2014 HTML5 Recommendation Native audio/video support replacing plugins

Detailed Timeline

  1. 1989: Proposal for the World Wide Web

    Event: Tim Berners-Lee submitted "Information Management: A Proposal" while working at CERN.

    It outlined a global hypertext system allowing researchers to share and link documents across different computer systems.

    Sources:

    • W3C Proposal Archive

  2. 1990: First Web Server, Browser, and Webpage

    Event: Tim Berners-Lee created the first web browser (WorldWideWeb), server (nxoc01.cern.ch), and website at CERN.

    This proved that HTTP, HTML, and URLs worked in practice, converting hypertext concepts into functional technology.

    Sources:

    • CERN Birth of the Web

  3. 1991: The Web Goes Public

    Event: Tim Berners-Lee shared the World Wide Web software publicly on the alt.hypertext newsgroup.

    This opened access to the public outside CERN, starting global growth and developer involvement.

    Sources:

    • W3C Announcement Archive

  4. 1994: W3C Founded

    Event: Tim Berners-Lee founded the World Wide Web Consortium (W3C) at MIT.

    It created an international standards organization to keep web technologies like HTML and CSS open and compatible across systems.

    Sources:

    • W3C Facts

  5. 1995: JavaScript and E-Commerce Launch

    Event: Brendan Eich created JavaScript at Netscape, while Amazon and eBay (AuctionWeb) launched commercial operations.

    JavaScript allowed dynamic browser scripting while e-commerce introduced commercial buying and selling online.

    Sources:

    • W3C JavaScript History
    • Amazon Company Timeline

  6. 1998: Incorporation of Google

    Event: Larry Page and Sergey Brin incorporated Google, launching search driven by the PageRank algorithm.

    Sorting sites by link relationships improved search relevance, making large volumes of web content easier to locate.

    Sources:

    • Google Official History

  7. 2004: Rise of Web 2.0 and Social Media

    Event: Facebook launched, and O'Reilly Media popularized the term "Web 2.0".

    Web design shifted from static reference pages to interactive platforms built around user-generated posts and media sharing.

    Sources:

    • O'Reilly Web 2.0 Article

  8. 2007: Launch of the iPhone

    Event: Apple released the original iPhone with a full desktop-class Safari browser.

    It expanded web usage to pocket devices, prompting widespread adoption of responsive site layouts.

    Sources:

    • Apple Newsroom Archives

  9. 2014: HTML5 Standard Published

    Event: W3C published HTML5 as an official recommendation.

    It standardized built-in browser support for video, audio, and interactive graphics without requiring third-party plugins like Flash.

    Sources:

    • W3C HTML5 Recommendation
