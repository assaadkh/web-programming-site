Detailed Timeline

  1. 1989: Proposal for the World Wide Web

    Event: Tim Berners-Lee submitted his proposal "Information Management: A Proposal" at CERN.

    It laid the foundation for the World Wide Web, introducing the concept of a global hypertext system to link and access information across different computers.

    Sources:

    • W3C Proposal Archive

  2. 1990: First Web Server, Browser, and Webpage

    Event: Tim Berners-Lee created the first web browser (WorldWideWeb), web server (nxoc01.cern.ch / info.cern.ch), and webpage at CERN.

    Demonstrated the practical functionality of HTTP, HTML, and URLs, turning theoretical concepts into working tech.

    Sources:

    • CERN Birth of the Web

  3. 1991: The Web Goes Public

    Event: Tim Berners-Lee announced the World Wide Web software publicly on the alt.hypertext newsgroup.

    Opened the Web to the global public outside CERN, initiating widespread adoption and development.

    Sources:

    • W3C Announcement Archive

  4. 1993: CERN Releases WWW into the Public Domain & NCSA Mosaic Launches

    Event: CERN placed the Web source code in the public domain without royalties, and NCSA released Mosaic, the first widely popular graphical web browser.

    Removing financial and legal barriers enabled exponential growth, while Mosaic made navigating the Web user-friendly for non-technical users.

    Sources:

    • CERN Royalty-Free Declaration
    • NCSA Mosaic History

  5. 1994: Founding of the W3C (World Wide Web Consortium)

    Event: Tim Berners-Lee founded the World Wide Web Consortium (W3C) at MIT.

    Established an international standard-setting body to ensure the open Web remained interoperable and standardized (HTML, CSS, etc.).

    Sources:

    • W3C History

  6. 1995: Launch of JavaScript, PHP, and Commercial E-Commerce

    Event: Brendan Eich created JavaScript at Netscape, while Amazon and eBay (AuctionWeb) were founded.

    JavaScript brought interactive client-side scripting to web pages, turning static documents into rich applications, while e-commerce transformed global retail.

    Sources:

    • MDN JavaScript Guide
    • Amazon Overview
    • eBay Company History

  7. 1998: Incorporation of Google

    Event: Larry Page and Sergey Brin incorporated Google, introducing the PageRank search algorithm.

    Revolutionized search engine accuracy and speed, making the exponentially growing web easily searchable and navigable.

    Sources:

    • Google Official History

  8. 2004: Emergence of "Web 2.0" and Social Networking

    Event: Mark Zuckerberg launched Facebook, and O'Reilly Media popularized the term "Web 2.0".

    Marked the shift from read-only static websites to user-generated content, rich internet applications, and global social platforms.

    Sources:

    • O'Reilly Web 2.0 Article

  9. 2007: Launch of the iPhone and Mobile Web Explosion

    Event: Apple introduced the original iPhone with a desktop-class Safari web browser.

    Transformed the Web from a desktop-centric experience into an always-on mobile experience, driving responsive web design.

    Sources:

    • Apple Newsroom Archives

  10. 2014: HTML5 Reaches Official Recommendation

    Event: W3C officially published the HTML5 Recommendation.

    Standardized native web support for video, audio, canvas drawing, and mobile integration without requiring proprietary plugins like Flash.

    Sources:

    • W3C HTML5 Recommendation

  11. 2015: HTTP/2, Let's Encrypt, and ECMAScript 2015 (ES6)

    Event: IETF published HTTP/2 (RFC 7540), Let's Encrypt launched free automated SSL/TLS certificates, and Ecma released ES6.

    Overhauled web transmission speed, spurred the HTTPS encryption standard across the web, and modernized JavaScript for application development.

    Sources:

    • IETF HTTP/2 RFC 7540
    • Let's Encrypt About Page

  12. 2017–2019: WebAssembly (Wasm) Becomes 4th Web Standard

    Event: Major browser engines shipped WebAssembly MVP in 2017, and W3C ratified it as an official recommendation in 2019.

    Allowed languages like C, C++, Rust, and Go to run in browsers at near-native binary speed, enabling desktop software directly in web browsers.

    Sources:

    • W3C WebAssembly Press Release

  13. 2018: GDPR & Global Web Privacy Paradigm Shift

    Event: The European Union's General Data Protection Regulation (GDPR) went into effect.

    Reshaped web data tracking, analytics, and user privacy rights globally, accelerating the decline of third-party tracking cookies.

    Sources:

    • European Commission Data Protection

  14. 2020: The Official End of Adobe Flash Player

    Event: Adobe permanently terminated support for Flash Player and blocked Flash content execution.

    Marked the definitive end of proprietary browser plugins, solidifying open standards like HTML5, CSS, and JavaScript.

    Sources:

    • Adobe Flash End of Life

  15. 2022: HTTP/3 Standardized over QUIC (RFC 9114)

    Event: IETF standardized HTTP/3 running over the UDP-based QUIC transport protocol.

    Solved TCP head-of-line blocking, enabled 0-RTT handshakes, and improved connection reliability across cellular and Wi-Fi networks.

    Sources:

    • IETF HTTP/3 RFC 9114

  16. 2022–Present: Generative AI & The Conversational Web

    Event: OpenAI released ChatGPT in November 2022, driving integration of LLMs and AI web agents across the Internet.

    Initiated the shift from traditional search link crawling toward conversational synthesis, natural language interfaces, and web automation.

    Sources:

    • OpenAI Announcement
